# ConsentPath · 隐私同意迁移演练台

纯浏览器本地运行的隐私说明（Privacy Notice）版本迁移演练工具。用 React + TypeScript + Vite 实现，
用来回答一个具体问题：**旧版说明里的一个勾选，升级到新版（用途拆分/合并/新增）后，哪些用途仍然有效、
哪些必须让用户重新确认、撤回会连带影响哪些下游用途。**

## 快速开始

```bash
npm install
npm run dev        # 本地开发（默认 http://localhost:5173）
npm test           # 运行全部 vitest 用例（75 个）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

所有数据保存在浏览器 `localStorage`，没有任何后端与网络请求；支持导出/导入 JSON 在团队间传递情景。

## 领域模型

- **说明版本（PrivacyVersion）**：草稿可编辑；发布后内容冻结不可改，只能基于它创建新的草稿分叉。
  版本通过 `parentVersionId` 构成继承链；目标版本不在旧版本的后继链上即**版本分叉**。
- **用途层级（Purpose）**：用途组（组节点，不持有同意）与叶子用途；`parentId` 构成树，
  `dependsOn` 声明本用途依赖的**上游**用途（DAG，允许同一上游被多个下游依赖；检测循环引用）。
- **版本间映射（PurposeMapping）**：一条 `旧用途 → 新用途` 规则。
  - 一个旧用途指向多个新用途 = **拆分**（如「体验优化」→「分析」+「个性化」）；
  - 多个旧用途指向同一新用途 = **合并**；来源旧同意一同意一拒绝时产生**合并冲突**，必须重新确认；
  - 映射首尾相接形成闭环 = **映射循环**。
- **地区规则（RegionRule）**：`opt-in`（默认拒绝）/`opt-out`（默认允许）/`notice`（仅告知）；
  必要用途恒同意且不可撤回；被禁用途勾选无效；迁移策略 `strict`（未映射用途必须重新确认）/
  `notice`（未映射用途按默认规则生效）。
- **同意记录（ConsentRecord）**：用户在某版本上「勾没勾选」的原始事实。

## 迁移与撤回判定规则

1. 地区禁止 > 必要用途 > 显式选择 > 上游依赖继承 > 地区默认值。
2. 只有用户**显式勾选**过的选择才会沿映射继承；opt-in 下的「未勾选=拒绝」不会被冻结成新版勾选，
   撤回上游后下游可按新版用途图重新计算。
3. 下游用途必须存在至少一个有效上游才会生效：撤回某用途后，直接/间接依赖它的用途一并失效
   （在 opt-out/notice 地区默认值也不能挽救级联失效）；显式拒绝优先级最高。
4. 严格策略下未映射或合并冲突的用途进入「待重新确认」暂停态，即便存在已授权上游也暂不生效，
   用户重新确认后解除。
5. 每一项结论都给出 `status`（继承/待确认/地区默认/禁止/必要）与文字理由；冲突带可定位坐标
   （版本、用途、映射、用户、地区、环路径）。
6. 撤回/授予重复执行是幂等的；事件日志记录每次操作后的完整有效状态与级联影响。

## 内置示例情景

- v1（2023）：单一「体验优化」+ 营销触达；
- v2（2024）：体验优化拆分为「分析」「个性化」，新增「定向广告」（依赖营销触达）；
- v3（2025 草案）：分析 + 营销合并为「增长洞察」，新增无来源的「AI 模型训练」。
- 用户：林晓(EU, opt-in/strict)、王浩(CN, opt-out/strict)、Alice(US, notice/notice)、陈默(BR，无地区规则)。

可演练：v1→v2 拆分继承、v2→v3 合并冲突、部分撤回与下游级联、重新确认、跨地区默认差异、地区缺失告警。

## 功能

- 五个工作台页：迁移演练、版本与用途（含映射编辑）、地区规则、用户与同意记录、检查与快照。
- 草稿自动保存（刷新恢复）、不可变发布版本、撤销/重做（Ctrl/⌘+Z、Shift+Z / Ctrl+Y）、
  命名情景快照（保存/恢复/删除，恢复可撤销）、JSON 导入导出、一键重置示例数据。

## 代码结构

```
src/core/        纯领域逻辑（无 React 依赖，全部可单测）
  types.ts       领域模型与结果类型
  graph.ts       用途树/DAG：叶子、环检测、下游闭包、映射环
  consent.ts     有效同意状态：地区规则、默认值、上游继承、暂停态
  migrate.ts     版本迁移规划：映射复合（拆分/合并/多跳）、冲突收集
  simulate.ts    演练动作：迁移落盘、部分撤回（级联）、重新确认（幂等）
  validate.ts    全量静态校验（健康检查页使用）
  seed.ts        内置示例数据
src/state/       reducer + 撤销重做历史 + localStorage 持久化 + 快照
src/pages/       五个工作台页面
src/test/        vitest 用例：迁移/图/同意/演练/状态层/校验/边界/UI 冒烟
```
